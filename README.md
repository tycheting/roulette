# 證券投資損益打卡與競賽系統

朋友間的私人投資競賽。管理員在 Google Sheets 建用戶與證券戶，用戶每月用手機打卡填本金與市值，系統算出排行榜與獎金池。

```
gas/                 Google Apps Script 後端
  Code.gs            API 主程式
  setup.gs           一鍵建立分頁
  appsscript.json    專案設定（時區、部署權限）
frontend/            React + Vite + Tailwind 前端
  src/lib/calc.js    核心計算純函式（與後端邏輯一致）
  src/api/gasClient.js
  src/pages/         WhoAmI / Dashboard / Checkin / Me
  public/            PWA manifest、Service Worker、圖示、圖片
```

## 部署步驟

### 1. 建立 Google Sheets 與後端

1. 開一份新的 Google 試算表，命名隨意。
2. 選單 **擴充功能 → Apps Script**，開啟指令碼編輯器。
3. 把 `gas/Code.gs` 的內容貼進預設的 `Code.gs`。
4. 左側 **檔案 → +** 新增一個指令碼檔命名 `setup`，貼上 `gas/setup.gs`。
5. 左側齒輪 **專案設定** 勾選「在編輯器中顯示 appsscript.json」，把 `gas/appsscript.json` 貼進去（重點是時區 `Asia/Taipei`）。
6. 在編輯器上方的函式下拉選 `setupSpreadsheet`，按 **執行**。第一次會要求授權，同意即可。三個分頁就建好了。
7. 右上 **部署 → 新增部署作業 → 類型選「網頁應用程式」**：
   - 執行身分：**我**
   - 具有存取權的使用者：**任何人**
   - 按部署，複製出現的網址（結尾是 `/exec`）。

> 之後每次修改 `Code.gs`，都要重新 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」**，否則線上跑的還是舊程式。

### 2. 本機跑前端

```bash
cd frontend
npm install
cp .env.example .env
# 編輯 .env，把 VITE_GAS_API_URL 換成上一步複製的 /exec 網址
npm run dev
```

打開 http://localhost:5173 就能用了。

### 3. 部署到 Vercel

1. 把整個專案推上 GitHub。
2. Vercel **New Project** 匯入該 repo。
3. **Root Directory** 設為 `frontend`（重要，否則找不到 package.json）。
4. Framework Preset 會自動偵測成 Vite，不用改。
5. **Environment Variables** 新增 `VITE_GAS_API_URL`，值是 `/exec` 網址。
6. Deploy。

手機開啟網址後，Safari 用「分享 → 加入主畫面」、Chrome 用「安裝應用程式」，就會變成獨立 App。

## 管理員日常操作

全部在 Google Sheets 上做，沒有後台介面。

### `Settings` 分頁

| 設定鍵 | 說明 |
|---|---|
| `競賽名稱` | 顯示在首頁標題 |
| `競賽結束日期` | `YYYY-MM-DD`，倒數計時的目標 |
| `是否開放打卡` | `TRUE` 開放、`FALSE` 關閉。改完最多 60 秒生效（有快取） |
| `當前打卡月份` | `YYYY-MM`。決定這期收哪個月的資料，**每期開始前記得改** |
| `獎金池比例` | 預設 `0.5` |
| `首頁橫幅圖網址` | 選填，留空不顯示 |

### `Users` 分頁

| 欄位 | 說明 |
|---|---|
| `用戶名` | 唯一，例如「小明」 |
| `證券戶清單` | 逗號分隔，例如 `台新,國泰` |
| `啟用` | `FALSE` 的人不會出現在名單與排行榜 |
| `顯示順序` | 身分選擇頁的排序 |
| `頭像網址` | 選填，留空自動生成字母頭像 |

### `Records` 分頁

只增不改。同一人同一期重送，系統會再寫一列新的，讀取時取時間戳記最新的那筆，所以你在這裡看得到每個人改過幾次。要手動補登就直接加一列，`來源` 欄填 `manual`。

## 計算規則

**本金**是自己口袋拿出來的錢的累計，只能增加。送出時若低於上期，後端會擋下。

**當期表現**排除了加碼的干擾：

```
新增本金   = 本期本金 − 上期本金
當期損益   = 本期(市值−本金) − 上期(市值−本金)
當期報酬率 = 當期損益 ÷ (上期市值 + 新增本金) × 100%
```

首次打卡沒有上期，當期損益就等於累計損益，分母用本期本金。

舉例：上期本金 100 萬、市值 110 萬（累計 +10%），本期加碼 50 萬、市值 162 萬。累計報酬率掉到 8%，但當期報酬率是 `20,000 ÷ (1,100,000 + 500,000) = 1.25%`，這才是本期真正的表現。

**排行榜**取每人各自最新的一筆紀錄，依當期報酬率排序。沒打卡的人用舊資料照排，但會標示資料月份與落後幾期。

**獎金池**每人以當期損益絕對值的 50% 出資，第一名整池帶走。冠軍實際淨得是總池扣掉自己那份。

例：小明 +20,000、阿凱 −5,000 → 出資 10,000 與 2,500 → 池子 12,500 → 小明淨得 2,500，阿凱應付 2,500。

## 圖片要放哪

兩個預留位置，都在 `frontend/public/images/`：

- **首頁橫幅** — 圖片丟進資料夾後，到 `Settings` 把 `首頁橫幅圖網址` 填成 `/images/banner.jpg`。留空就不顯示。
- **用戶頭像** — 圖片丟進資料夾後，到 `Users` 的 `頭像網址` 填 `/images/avatar-ming.jpg`。留空會用名字末字生成固定配色的頭像。

兩處都可以直接填外部 https 網址。

PWA 圖示在 `frontend/public/icons/`，已經放了可用的預設圖（票券造型）。要換成自己的就覆蓋同名檔案，尺寸維持 192×192 與 512×512。

## 已知限制

- **身分選擇沒有驗證效力**。任何人都能切換成別人送出資料。這是刻意的設計，朋友間信任模式。要防就得加 PIN，屆時 `Users` 加一欄、`handleCheckin` 多一道檢查即可。
- **iOS 無痕模式下 localStorage 會失效**，每次開啟都要重選身分。
- **設定改動最多 60 秒生效**，因為 `bootstrap` 有快取。打卡送出成功會主動清快取，所以排行榜是即時的。
- **不做推播通知**。要提醒大家打卡，直接在群組喊一聲比較實際。
